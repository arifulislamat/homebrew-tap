# homebrew-tap

Homebrew formulae for tools by [@arifulislamat](https://github.com/arifulislamat).

```sh
brew install arifulislamat/tap/cctwin
```

| Formula | Description |
|---|---|
| [cctwin](https://github.com/arifulislamat/cctwin) | macOS menu bar app to switch Claude Code between Claude accounts you own |

Formulae are updated automatically by each project's release workflow.
